# GenericUI Image API, GPU, Overlays, Canvases, PiP, & Media Guide

> **Root Repository**: [**GenericUI (`../README.md`)**](../README.md) | **Master Docs Index**: [**`docs/README.md`**](./README.md)  
> **Related Guides**: [Extensions Overview (`extensions.md`)](./extensions.md) · [Resources (`resources.md`)](./resources.md) · [Platform Backends (`backends.md`)](./backends.md) · [Overlay Extension (`../extensions/docs/overlay.md`)](../extensions/docs/overlay.md) · [Picture-in-Picture (`../extensions/docs/pip.md`)](../extensions/docs/pip.md) · [Media Extension (`../extensions/docs/media.md`)](../extensions/docs/media.md) · [Media Controls Extension (`../extensions/docs/mediacontrols.md`)](../extensions/docs/mediacontrols.md) · [Schema Extension (`../extensions/docs/schema.md`)](../extensions/docs/schema.md)

GenericUI cleanly separates its base multi-format **Image API** (`com.nexustools.genericui.image.*`), hardware **`backdrop-filter`** support on **`StyledComponent`**, **`StyledButton`**, & **`StyledContainer`** across all 9 backends (all 10 `CssFilter` ops), and **`AbstractCanvas`** VBlank timing base class in `:common` from its modular extensions for GPU compute ([`:extensions:graphics:gpu`](../extensions/docs/gpu.md)), offscreen GPU image processing ([`:extensions:graphics:imageprocessing`](../extensions/docs/imageprocessing.md)), pure interactive overlays ([`:extensions:ui:overlay`](../extensions/docs/overlay.md)), Picture-in-Picture ([`:extensions:ui:pip`](../extensions/docs/pip.md)), 2D/3D hardware canvases ([`:extensions:graphics:canvas2d`](../extensions/docs/canvas2d.md), [`:extensions:graphics:canvas3d`](../extensions/docs/canvas3d.md)), media playback ([`:extensions:media:media`](../extensions/docs/media.md)), and OS/keyboard media controls ([`:extensions:media:mediacontrols`](../extensions/docs/mediacontrols.md)).

---

## 1. Base `:common` Full Image API (`com.nexustools.genericui.image.*`) & Hardware `backdrop-filter`

Every GenericUI application has out-of-the-box access to a complete, cross-platform Image API in `:common`, plus full aesthetic `ComponentStyle` support (including hardware `backdropFilter` / `setBackdropBlur(...)` validated via `AestheticStylePolicy`) on **`StyledComponent`**, **`StyledButton`**, and **`StyledContainer`**:

| Class / Enum (`1 Class Per File`) | Responsibility |
| :--- | :--- |
| **`PixelFormat`** | `RGBA_8888`, `BGRA_8888`, `RGB_888`, `RGBA_F16`, `RGBA_F32`, `GRAY_8`, `GRAY_ALPHA_88` |
| **`ImageFormat`** | `PNG`, `JPEG`, `WEBP`, `GIF`, `APNG`, `BMP`, `ICO`, `TIFF`, `SVG` |
| **`ImageColorSpace`** | `SRGB`, `LINEAR_SRGB`, `DISPLAY_P3`, `REC_2020_PQ`, `REC_2020_HLG`, `ADOBE_RGB` |
| **`ImageMetadata`** | Dimensions, `ImageFormat`, `ImageColorSpace`, EXIF orientation, DPI, frame count, ICC profile bytes |
| **`ImageBuffer`** | CPU-accessible pixel buffer with width, height, stride, `PixelFormat`, `ImageColorSpace`, and pixel read/write helpers |
| **`AnimatedImage` & `ImageFrame`** | Multi-frame animated image container and per-frame timing/disposal descriptors |
| **`ImageLoader`** | Decode, encode, probe metadata, load from `Resource.ResourceID`, and cache remote URLs via `ImageCacheManager` |
| **`AppleIconTileComposer`** | Pure-Kotlin Chrome-style rounded white squircle compositor (`composeImageBuffer`, `composeRgba`) used at runtime on macOS when no explicit Apple icon is configured |
| **`LibJpegCodec` / `LibPngCodec` / `LibWebpCodec`** | Built-in multiplatform JPEG, PNG, WebP, and BMP/PPM codecs backing native platform loaders (`ImageIO`, `BitmapFactory`/`ImageDecoder`, Apple `ImageIO` + CoreGraphics SVG rasterization, `WIC`, `GdkPixbuf`, `QImage`, browser `createImageBitmap`) |

## 2. `:extensions:graphics:gpu` & Offscreen `:extensions:graphics:imageprocessing`

- **`:extensions:graphics:gpu`**: Unified GPU device, shader, and offscreen context foundation (`GpuDevice`, `GpuOffscreenContext`, `VKContext` primary with `#version 450` SPIR-V and **MoltenVK** on `:desktop` `macosMain` & `:mobile` `iosMain`, `GLContext` fallback with `#version 300 es` and **Google ANGLE** over Direct3D 11 on `:desktop` `mingwMain`).
- **`:extensions:graphics:imageprocessing`**: Processes `:common` `ImageBuffer` instances offscreen on the GPU via `GpuImageProcessor`, `GpuImageFilterChain`, and `GpuImageKernel`.

## 3. `:extensions:ui:overlay` — Pure `LayeredContainer` Chrome & `YoutubePlayerOverlay`

[`:extensions:ui:overlay`](../extensions/docs/overlay.md) (`com.nexustools.genericui.ext.overlay`) is a standalone, 100% generic KMP extension depending **only on `:common`**. It is enabled automatically by `media()`, `pip()`, `canvas2d()`, and `canvas3d()` (or directly via `overlay()`):

- **Pure, Background-Free Hosts, `style.scss` / Raw `theme.scss` Templates, & `.hidden` Fading**: `OverlayHost` / `OverlayHostBox` and `Overlay` / `FadingOverlay` auto-attach zero default preset chrome or scrims until explicitly composed. All static chrome, `:hover`/`:focus`/`:disabled` states, and `.hidden` (`opacity: 0; pointer-events: none; cursor: none;`) fade-in/out `@keyframes` animations live in `:extensions:ui:overlay/src/commonMain/resources/styles/style.scss` (executed by VBlank-synced `Animator` via `SystemCssAnimationController` on `:system` and native browser CSS on `:web`). Meanwhile, `:extensions:ui:overlay/src/commonMain/resources/styles/theme.scss` is packaged solely as an uncompiled source template inside library artifact metadata (`META-INF/genericui/themes/<scopeId>.scss` & `META-INF/genericui/module-resources/<scopeId>.json`, never compiled/integrated into the library artifact); only the consumer app's `:gradle-plugin` build extracts and compiles it against `genericui { theme { ... } }` `$accent` variables into `GenericUiGeneratedThemeStyleSheet` / `gui/genericui-theme.css` solely in the consumer app, with zero direct Kotlin component styles.
- **9 Pure-Bezier Vector Icons & Styled Transport Controls**: [`OverlayIcons`](../extensions/ui/overlay/src/commonMain/kotlin/com/nexustools/genericui/ext/overlay/OverlayIcons.kt) resolves 9 SVG drawables from **`com.nexustools.genericui.ext.overlay.res.R.drawable`** (`ic_play`, `ic_pause`, `ic_rewind`, `ic_fast_forward`, `ic_stop`, `ic_next`, `ic_previous`, `ic_fullscreen_enter`, `ic_fullscreen_exit`), powering `OverlayControlButton` (`CIRCLE_PILL` / `CENTER_PRIMARY` / `CENTER_SECONDARY` / `INNER_PILL` variants + hardware `backdropFilter` glass support), `OverlayPlayPauseButton`, `OverlayFullscreenButton`, and `OverlayControlButtons`.
- **`YoutubePlayerOverlay` & `HybridOverlayDifferenceController`**: Full 3-zone HUD (`topBar`, `centerZone`, `bottomBar` with configurable `ABOVE_CONTROLS` / `BELOW_CONTROLS` timeline placement), persistent auto-hide-exempt `subtitleBanner` (mounted outside the `.hidden` fading overlay in `OverlayHostBox`'s persistent layer slot), hover timeline preview (`seekHoverBubble`, with only dynamic `left` `%` updated at runtime), registered popover pinning, and adaptive switching between `HybridOverlayLayoutMode.SMALL_MOBILE_PORTRAIT` and `HybridOverlayLayoutMode.MEDIUM_LARGE`.
- **Shared Behavior Controllers**: `AutoHideController` (pin reasons, `"hidden"` class toggling, and immediate Picture-in-Picture suppression via `setPictureInPictureMode(true)`) and `OverlayInputRouter` (`>= 5px` stage drag-slop for `startSystemMove()`, `250ms` click debounce on Desktop/Web, tap-to-toggle on touch-primary targets, double-click fullscreen toggle, `isolateInteractiveComponent(...)`, and configurable shortcuts ignored while text inputs have focus).

## 4. `:extensions:graphics:canvas2d` & `:extensions:graphics:canvas3d` (with Overlay Hosts & Fail-Fast Registries)

All canvases inherit from `:common`'s `AbstractCanvas` (`registerVBlankRender { deltaMs -> ... }`), attach optional overlays via `:extensions:ui:overlay` (`Canvas2DOverlayHost`, `ScrollCanvas2DOverlayHost`, `Canvas3DOverlayHost`, `ScrollCanvas3DOverlayHost`), and fail fast (`IllegalStateException` / `UnsupportedOperationException`) via [`Canvas2DExtension`](../extensions/graphics/canvas2d/src/commonMain/kotlin/com/nexustools/genericui/ext/canvas2d/Canvas2DExtension.kt) and [`Canvas3DRegistry`](../extensions/graphics/canvas3d/src/commonMain/kotlin/com/nexustools/genericui/ext/canvas3d/Canvas3DRegistry.kt) if no platform backend provider is registered:

| Extension & Classes | Windows (`mingwMain`) | macOS (`macosMain`) | Linux (`gtk` / `kde`) | JVM Swing (`jvmMain`) | Android (`androidMain`) | iOS & iPadOS (`iosMain`) | Web (`web`) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`:extensions:graphics:canvas2d`**<br/>`Canvas2D`, `ScrollCanvas2D`, `CurveEditor` | Direct2D (`ID2D1RenderTarget`) | CoreGraphics (`CGContext`) | Cairo / `QPainter` | `Java2D` (`Graphics2D`) | `android.graphics.Canvas` | CoreGraphics (`CGContext`) | HTML5 `CanvasRenderingContext2D` |

## 5. `:extensions:media:media`, `:extensions:ui:pip`, & `:extensions:media:mediacontrols`

### A. `:extensions:media:media` (`VideoPlayer`, `VideoFragment`, `AudioPlayer`, `AudioAnalyzer`, `SeekBar : StyledSlider`, `ExpandingVolumeSlider : Composite`, `MediaExtension`)
- **Transparent Codec Introspection Without Player Instantiation**: [`MediaExtension`](../extensions/media/media/src/commonMain/kotlin/com/nexustools/genericui/ext/media/MediaExtension.kt) delegates codec and capability queries directly to the registered [`MediaCodecSupportProvider`](../extensions/media/media/src/commonMain/kotlin/com/nexustools/genericui/ext/media/MediaCodecSupportProvider.kt) (`isVideoCodecSupported(VideoCodec)`, `isAudioCodecSupported(AudioCodec)`, `getSupportedVideoCodecs()`, `getSupportedAudioCodecs()`, `getMediaCapabilities()`, `supportsAudioTrackSelection()`, `supportsSubtitleTrackSelection()`). LibVLC desktop/Swing backends use [`LibVlcCodecSupportProvider`](../extensions/media/media/src/commonMain/kotlin/com/nexustools/genericui/ext/media/LibVlcCodecSupportProvider.kt) (flat `true` with zero probe overhead), while Android, iOS, and Web use [`CachingMediaCodecSupportProvider`](../extensions/media/media/src/commonMain/kotlin/com/nexustools/genericui/ext/media/CachingMediaCodecSupportProvider.kt) (`AtomicReference` lock-free cache).
- **Dynamic `@SchemaData` Player Settings (`VlcConfiguration`)**: Exposes runtime LibVLC audio output/device selection, video renderer (`--vout`), hardware decoding (`--avcodec-hw`), deinterlacing, S/PDIF passthrough, and caching directly via `MediaExtension.hasConfigurablePlayerSettings()`, `getPlayerSettingsSchema()`, `getPlayerSettingsValues()`, and `applyPlayerSettingsValues(...)` powered by [`:extensions:data:schema`](../extensions/docs/schema.md).
- **`SeekBar : StyledSlider`, `ExpandingVolumeSlider : Composite`, & `style.scss`/`theme.scss` Styling**:
  - `SeekBar` extends `:common`'s `StyledSlider : Composite` (inheriting `.styled-slider-track` `StyledButton` at `z-index: 1`, `$accent`-colored `.styled-slider-progress` `StyledComponent` at `z-index: 3` with `pointer-events: none`, and `.styled-slider-knob` `StyledButton` at `z-index: 4`) and appends `preloadSegment: StyledComponent` (`.seek-bar-preload`, `z-index: 2`, `pointer-events: none`) to `compositeChildren` — with **ZERO custom `SeekBarNativeImpl`**.
  - `ExpandingVolumeSlider : Composite` combines the mute/volume `StyledButton` (`.expanding-volume-mute-btn`) + 5 pure-Bezier SVGs in `com.nexustools.genericui.component.media.res.R` (`MediaVolumeIcons`) and a **`StyledSlider`** (not `SeekBar`), styled via `:extensions:media:media`'s `style.scss` + raw `theme.scss` template (packaged uncompiled in library metadata and compiled solely by the consumer app's `:gradle-plugin` build against `genericui { theme { ... } }` `$accent` into `GenericUiGeneratedThemeStyleSheet` / `gui/genericui-theme.css`, with zero direct Kotlin component styles beyond runtime-dynamic `%` widths/offsets). [`VideoOverlayHost`](../extensions/media/media/src/commonMain/kotlin/com/nexustools/genericui/ext/media/overlay/VideoOverlayHost.kt) + [`YoutubeMediaOverlayHelper`](../extensions/media/media/src/commonMain/kotlin/com/nexustools/genericui/ext/media/overlay/YoutubeMediaOverlayHelper.kt) mount `SeekBar` and `ExpandingVolumeSlider` directly into `YoutubePlayerOverlay`.
- **Picture-in-Picture (`:extensions:ui:pip`)**: Pairs seamlessly with [`FragmentPipHelper`](../extensions/docs/pip.md) / `@PiPCompatible` across Android, iOS (`AVPictureInPictureController`), Desktop/Swing floating windows, and Web (`documentPictureInPicture` / native `<video>` PiP / in-place fallback).

### B. `:extensions:media:mediacontrols` (`MediaControlsSession` & Default Real Factory)
- Standalone extension (`com.nexustools.genericui.ext.mediacontrols`) depending **only on `:common`**:
  - [`MediaControlsRegistry`](../extensions/media/mediacontrols/src/commonMain/kotlin/com/nexustools/genericui/ext/mediacontrols/MediaControlsRegistry.kt) initializes its factory property automatically via `internal expect fun defaultPlatformMediaControlsFactory()` ([`DefaultPlatformMediaControlsFactory.kt`](../extensions/media/mediacontrols/src/commonMain/kotlin/com/nexustools/genericui/ext/mediacontrols/DefaultPlatformMediaControlsFactory.kt)), with real platform `actual` implementations across **all targets** (Windows `ITaskbarList3` + SMTC + `WM_APPCOMMAND`/`VK_MEDIA_*`, macOS `MPRemoteCommandCenter` + `MPNowPlayingInfoCenter`, Linux MPRIS2 / `XF86Audio*`, JVM Swing keyboard/system controls, Android `MediaSession`, iOS & iPadOS `MPRemoteCommandCenter` / `MPNowPlayingInfoCenter`, and Web `navigator.mediaSession`).
  - Zero silent no-op fallback: clearing `MediaControlsRegistry.factory = null` causes `MediaControlsSession()` to fail fast with an `IllegalStateException`.
